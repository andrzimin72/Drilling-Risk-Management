# Drilling Risk Management System — Architecture

**Version:** 1.0.0 (Enterprise Edition)  
**Client:** Gazprom Neft PJSC  
**Last Updated:** 2026-07-31

---

## 1. High-Level Overview

The system is a **multi-agent AI swarm** that processes oil & gas engineering data (DDRs, LAS logs, surveys, completion designs) and automatically identifies, scores, and visualizes drilling risks.

### Core Principles
- **Modular Architecture** — Each agent is independent and can be replaced/extended
- **Async Parallel Execution** — Agents run concurrently via `asyncio`
- **Bilingual Support** — Full Russian/English localization (Gazprom Neft ready)
- **Unit Agnostic** — Handles both Imperial (ft, ppg) and Metric (m, g/cm³)
- **Enterprise Resilient** — SQLite caching, crash recovery, OpenTelemetry
